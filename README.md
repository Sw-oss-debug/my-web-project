## ✨ 核心功能 / Core Features
- **AI 客戶支援：** 全天候自動處理常見問題、訂單追蹤和線索分配。
- **互動式投資報酬率計算器：** 動態模擬成本節約與轉換率提升。
- **進階儀錶板：** 包括聊天頁面 (`chat.html`)、管理控制台 (`admin.html`) 和支付結帳頁面 (`結帳.html`)。
- **現代使用者介面：** 簡潔、高轉換率的科技感深色模式設計。

## 🛠️ 技術堆疊及設置 / Tech Stack
- **前端：** 原生 JS / TS、現代 HTML5 和受 Tailwind 啟發的響應式 CSS 佈局。
- **無伺服器架構：** 輕量級且 100% 免費託管（買家無需承擔任何維護成本）。
